# 서버1.15.31 / Android1.8.8(188) — GPS 알림 숨기기
- GPS 기록 알림에 GPS 알림 숨기기 동작을 추가했다. 알림창에서 바로 해당 GPS 채널의 Android 설정을 연다.
- 앱 메뉴와 알림 설정에도 GPS 알림 숨기기를 추가하고 이동 기록 설정 상단에 현재 알림 표시 상태와 안내를 표시한다. 작은 화면에서 버튼이 가려지지 않도록 스크롤을 지원한다.
- 사용 방법: GPS 알림 숨기기 → GPS 이동 기록 항목의 알림 허용 끄기. Android에서 사용자가 한 번 변경해야 하며 업데이트만으로 기존 채널의 알림 설정을 강제로 변경하지 않는다.
- 기존 ontech_location_history 채널 ID를 유지하므로 사용자가 숨긴 설정을 새 채널 생성으로 초기화하지 않는다. 채팅 알림 채널과 위치 기록/공유 설정은 별도다.
- 1분 간격·48시간 위치 기록, foreground service, 사용자 중지 동작을 유지한다. Android 실행 중인 앱 표시는 시스템에서 유지할 수 있다.
- 서버Setup1.15.31에 공식 APK1.8.8을 포함한다. 운영 설치 및 휴대전화 직접 설정 변경은 하지 않는다.
