# 1.9.0 위치 조회 변경

- 친구 프로필에는 현재 위치 확인만 제공하며 직접 내 위치 보내기는 제거했습니다.
- POST /api/rooms/{room}/location은 HTTP 410을 반환하고 좌표를 저장하지 않습니다.
- Android 1.6.0에서 내 위치 조회 허용 → 모두에게 허용을 선택합니다.
- 기기별 location-sharing PATCH: enabled=true, scope=all_friends. 개인별 선택은 새 UI에서 제거했습니다.
- 친구 범위는 /api/friends와 동일한 현재 활성 사용자 전체이며 신규 사용자도 포함합니다. 본인·미등록·비활성 계정은 제외합니다.
- 자동 공유 기본값은 꺼짐입니다. 기존 선택 공유는 본인이 모두에게 허용으로 변경하기 전까지 자동 확대하지 않습니다.
- 자동 응답은 요청 시 새 위치 1회 측정, 현재 세션·요청 대상·기기·공유 revision을 재검증합니다.
- 공유 중지·범위 변경은 처리 중인 자동 요청을 취소하며, 비활성/탈퇴·로그아웃 이후 응답은 거부합니다.
- 자동 공유를 켜지 않은 경우 기존 조회 요청에 대한 본인의 개별 동의 응답은 유지합니다. 임의 대상에게 먼저 전달하는 경로는 없습니다.
- 채팅 입력창 옆 위치 버튼은 다시 추가하지 않습니다.
- 적용 순서: 서버 1.9.0 업데이트 → Android 1.6.0 설치 → 본인 기기에서 모두에게 허용 설정.
