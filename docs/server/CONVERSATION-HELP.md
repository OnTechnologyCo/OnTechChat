## 사용 방법
1. AI 대화의 친구/대화 선택을 누릅니다.
2. 친구/참여 대화방을 선택하고 최근 20/50/100/200개 또는 날짜 범위를 지정합니다.
3. 실제 전달할 텍스트·개수·시각·시간대를 미리 확인합니다. 첨부/인증번호/삭제/만료 메시지는 제외합니다.
4. 대화 요약, 약속·할 일, 답장 초안, 직접 질문을 선택하고 전달·분석 버튼을 누릅니다.
5. 근거 메시지를 열어 원문을 확인합니다. 답장 초안은 복사하거나 입력창에 넣고 사용자가 직접 전송합니다.
## 데이터 및 권한
- friends.list / conversations.list / conversations.messages는 전용 서버 읽기 도구 레지스트리로 제공합니다.
- 로그인 세션의 사용자로만 조회하며, 최고관리자도 참여하지 않은 채팅은 읽지 못합니다.
- 미리보기 토큰은 사용자·대화방·메시지 ID·내용 해시·시간대에 묶입니다. 클라이언트의 본문이나 사용자 ID를 AI 입력으로 신뢰하지 않습니다.
- 분석 실행 전/각 분할 호출 전후/결과 조회 시 원문과 접근 권한을 다시 검사합니다.
- 미리보기는 ID/해시만 서버 메모리에 보관합니다. 결과 텍스트는 최대 15분 서버 메모리에만 보관하고 원문 삭제/비우기/권한 변경에 폐기합니다.
- 조회/응답은 no-store이며 UI는 닫기·로그아웃·검증 실패 시 메모리/화면 결과를 지웁니다. 창을 닫아도 서버의 TTL 내 결과는 만료까지 존재할 수 있습니다.
- 원문·분석 결과를 채팅 기록/디스크/운영 로그에 추가 저장하지 않습니다. 기존 AI 제공자의 데이터 처리 정책은 적용됩니다.
- 복사하거나 입력창에 넣은 초안은 사용자가 가져온 텍스트이므로 원문 삭제로 이미 복사한 외부 텍스트까지 회수하지 않습니다.
## 범위와 제한
- 목록 페이지 최대100개, 선택 텍스트 최대200개/96KiB. 실제 포함 개수와 시각·ID·부분 포함 여부를 표시합니다.
- 긴 대화는 원문 ID를 유지해 UTF-8 경계에서 분할하고 최대8개 부분 분석 후 취합합니다. 문맥이 너무 작으면 범위를 줄이도록 안내합니다.
- 근거가 없는 담당자/기한은 확인 필요, 사실과 추론을 구분하도록 지시합니다. IANA 시간대 DB를 포함해 다른 Windows PC에서도 동작합니다.
- 선택 대화 분석에서는 CLI 웹/파일/셸/MCP 도구를 비활성화합니다. 사적 대화 원문의 외부 검색 전송을 막으며 일반 AI 채팅의 범용 웹검색은 유지합니다.
- 첫 버전은 텍스트 분석만 지원합니다. 분석은 대화 전체를 영구 기억하거나 자동으로 다른 친구의 채팅을 탐색하지 않습니다.
- DB/환경변수 마이그레이션 없음. 서버 재시작 시 임시 미리보기·결과 토큰은 만료됩니다.
