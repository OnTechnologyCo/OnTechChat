# 1.10.0 Windows 설치 수명 주기 복구
- 통합 EXE를 Windows GUI subsystem으로 빌드하며 빌드 스크립트에서 PE 형식을 검사한다.
- 바탕화면·시작 메뉴에 아이콘이 있는 .lnk를 생성하고 기존 관리 메뉴 .cmd를 제거한다.
- HKLM Run의 OnTechChatTray 자동 시작을 등록한 뒤 실제 값을 읽어 검증한다.
- 설치 완료 후 Explorer 사용자 토큰으로 숨김 트레이를 시작하고 창 생성 여부를 확인한다.
- 업데이트/제거 시 서비스 재시작을 비활성화하고 정상 중지를 요청한다.
- 남은 프로세스는 전체 경로가 이 설치의 서버·트레이·관리 EXE와 일치할 때만 종료한다.
- 파일 교체 실패 시 이전 프로그램을 복원하고, 이후 설치 단계 실패 시 이전 설정과 실행 파일 복원을 시도한다.
- 제거 작업은 설치 폴더 밖에서 실행하여 자체 EXE와 작업 디렉터리 잠금을 피한다.
- 삭제 중 잠긴 파일 때문에 실패해도 소유권 표식을 복원하여 재시도를 허용한다.
- 방화벽/자동 시작/바로가기는 독립적으로 정리하며, 오류가 남으면 성공으로 표시하지 않는다.
- 데이터까지 삭제 여부는 제거 시 사용자가 선택한다. 보존을 선택한 데이터는 남는 것이 정상이다.
- 제거 도구 임시 폴더는 프로세스 종료 후 정리하며 실행 실패 시 재부팅 삭제 예약을 사용한다.
- 외부 Caddy와 다른 프로그램은 제거하지 않는다.
- 최신 작업/실기 검증 범위는 docs/WORK_STATUS.md를 확인한다.
