# OnTechChat Server 1.15.22 — 메일 수집 테스트와 실제 전달 진단

## 설치 후 실행
기존 서버 PC에서 Setup을 덮어 설치합니다. 서버 설정의 버전이 1.15.22인지 확인합니다.
네이버 메일에서 제목에 포함할 문장과 여러 수신 사용자를 선택합니다.
자동 전달을 켠 후 저장 후 적용하면 백그라운드 수집이 시작됩니다.
메일 수집 테스트는 화면의 메일 설정으로 즉시 1회 실행하고 조건에 맞는 제목+본문을 실제 개인 수신함으로 전달합니다. 자동 수집이 꺼져 있어도 수동 테스트는 가능합니다.

## 표시되는 결과
로그인 → 폴더 → UID 검색 → 제목 일치 → 본문 디코딩 → 사용자별 메시지 생성 단계를 검사합니다.
확인/일치/본문처리/생성/중복/제외/오류 건수와 각 UID의 결과를 보여 줍니다.
실패 단계 및 오류 상세를 진단 결과 복사 버튼으로 복사할 수 있습니다. 진단에는 메일 제목/본문/인증번호/비밀번호를 넣지 않습니다.
연결·폴더만 확인 버튼은 메일 전달이나 설정 저장을 하지 않습니다.

## 수정 사항
자동 수집과 수동 테스트에 같은 IMAP/파서/메시지 저장 코드를 적용합니다.
제목은 일반 포함 문자열로만 비교하며 영어 대소문자/연속 공백/보이지 않는 공백을 정규화합니다.
발신자·DMARC·인증 식별자·코드 추출 정규식은 사용하지 않습니다.
구형 code_pattern은 설정 호환용으로만 읽고 새 저장값은 subject_filter로 통일합니다.
Windows에서 EUC-KR/CP949 한글 제목/본문을 디코딩합니다.
제목 불일치 메일의 본문은 디코딩하지 않으며 디코딩 오류를 조용히 버리지 않습니다.
수동 검사는 최근 24시간 UID 중 마지막 50개 후보와 설정된 분 단위 범위를 재검사합니다. 이미 지나간 커서로 누락된 메일도 이 범위 내에서 복구하며 커서를 변경하지 않습니다.
UID+수신 사용자 기준 48시간 중복 방지 이력(최대 2만 건)을 기존 암호화 저장소에 기록합니다. 수신자 선택 해제 시 숨은 기본 수신자를 복원하지 않습니다.
메일 카드가 subject/body를 표시하며 만료 시 null DOM 접근 오류 없이 내용을 지웁니다.
읽음 표시·원본 메일 삭제·임의 HTML 실행·첨부파일 전달은 하지 않습니다.

## 검증 범위
IMAP fixture로 수동/자동 수집부터 개인 수신함 API, 다중 사용자 격리, 커서 보존, 중복, 실패 단계, 문자 인코딩을 검증합니다.
브라우저에서 설정/실제 테스트 버튼/결과 표시/만료를 검증합니다.
실제 외부 설치 PC와 사용자의 네이버 계정에는 접속하지 않았습니다. 실제 계정의 성공 여부는 새 수집 테스트 결과로 확인해야 합니다.
Android APK는 기존 1.8.3(183)을 유지합니다. Setup에 포함된 서버 Web UI로 제공됩니다.
