# 서버1.15.17 / Android1.8.3(183)

## 첨부 입력창
- 사용자 대화와 AI 대화 모두 파일 선택 시 서버로 전송하지 않습니다.
- 둥근 입력창 위쪽에 작은 이미지 미리보기/파일명/크기/취소 버튼을 표시합니다.
- 전송 버튼 또는 Enter를 누르면 첨부부터 업로드하고 메시지를 보냅니다. Shift+Enter는 줄바꿈입니다.
- 한 번에4개, 일반 대화 파일당100MB, AI 첨부 합계20MB까지입니다. Android 선택창도 여러 파일을 지원합니다.
- AI방 파일만 전송하면 첨부 내용을 확인해 달라는 기본 질문을 함께 보냅니다.
- 실패하면 남은 첨부/문구를 유지합니다. 이미 완료한 첨부는 재전송하지 않으며 응답 유실 재시도는 같은 client ID를 사용합니다.
- 선택한 첨부는 방별 현재 브라우저 메모리에만 보관합니다. 새로고침/로그아웃하면 미전송 첨부가 해제됩니다.
- 전송 중 다른 방으로 이동해도 원래 방에 전송하며 새 방의 작성 내용을 지우지 않습니다.

## 뒤로 가기
- 대화방에서 누르면 채팅 목록으로 이동합니다. 방 탈퇴/대화 삭제가 아닙니다.
- 설정 탭/서버 설정 창에서는 메인 화면으로 돌아갑니다.
- 메인에서 다시 누르면 앱을 백그라운드로 내립니다. 작성 중인 방별 초안은 화면 이동 시 유지합니다.
- Android13 이상 플랫폼 callback과 구형 OnBackPressed를 연결합니다.
- 서버 UI와 APK를 모두 업데이트해야 전체 변경이 적용됩니다. 기존 시작 지연 업데이트/서명 검증 정책은 유지합니다.

## 검증
- 실제 Chrome+테스트 API22개: 선택 시 네트워크 전송 없음, 썸네일 디코딩, 취소, 전송 순서, 파일만 전송, 실패/응답 유실/부분 실패 재시도, 방 격리, 로그아웃 정리, 뒤로 가기와 초안 유지 통과.
- 모바일 폭 화면에서 미리보기/입력/첨부/전송 배치 확인. 외부 계정·실제 사용자 데이터 사용 없음.
- root build.ps1 -Target All -Validation Core로 APK/Setup 및 관련 검사를 수행합니다. 최종 결과/해시는 docs/WORK_STATUS.md 참조.
- 연결된 Android 기기와 설치된 에뮬레이터가 없어 실제 버튼/제스처·키보드·파일 선택·설치 동작은 미검증입니다.
- DB 마이그레이션/환경변수 추가 없음. 운영 서비스 설치·재시작 없음.
