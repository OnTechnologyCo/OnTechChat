# OnTechChat Server 1.15.34 — 자동 HTTPS / Inno Setup

서버 설정 → 외부 접속 → 도메인 HTTPS 자동 설정에서 도메인을 입력하고 Let's Encrypt 약관에 동의한 뒤 설정·적용합니다. 별도 인증서 프로그램 설치 없이 무료 공인 인증서를 발급하고 자동 갱신합니다. Android 앱은 기존 1.8.10(190)을 그대로 사용합니다.

## 설정 순서

1. 실제 서버에 OnTechChat-Server-Setup-v1.15.34-x64.exe를 설치합니다.
2. Cloudflare에서 A 레코드 chat을 서버 공인 IP로 지정하고 DNS 전용(회색 구름)을 유지합니다. 잘못된 AAAA 레코드가 있으면 실제 IPv6 연결에 맞게 정리합니다.
3. 서버 PC의 트레이 → 서버 설정 → 외부 접속에서 chat.ontechdev.com을 입력합니다. https://, 포트, 경로를 넣지 않습니다.
4. 인증서 약관에 동의하고 자동 HTTPS 설정·적용을 누릅니다. 기존 IP 접속·인증서·수신 포트와 공유 주소는 유지합니다.
5. 같은 화면의 서버 Windows 방화벽에 443 허용을 누르고 Windows 관리자 승인을 진행합니다. 이 버튼은 서버 PC의 localhost 설정 화면에서만 사용할 수 있습니다. 휴대전화에서는 설정 저장과 상태 조회가 가능합니다.
6. 공유기 뒤의 서버라면 외부 TCP 443을 해당 서버의 TCP 443으로 포트 전달합니다. 외부 443 접근이 차단되거나 CGNAT 환경이라면 이 자동 발급 방식은 작동하지 않습니다. 프로그램이 공유기를 자동 설정하지 않습니다.
7. 인증서 다시 확인을 누릅니다. 중복 요청은 합쳐지고 재시도는 최소1분 간격입니다. 최초 확인은 최대90초가 걸릴 수 있습니다.
8. 공인 인증서 확인 완료 후 휴대전화 Wi-Fi를 끄고 https://chat.ontechdev.com으로 접속합니다. 기존 IP 주소로도 계속 접속할 수 있습니다. 도메인에서 처음 접속하면 로그인해야 합니다.

## 동작 및 제한

- 서버 자체 HTTPS 수신기를 443에 추가하고 TLS-ALPN-01로 인증합니다. 외부443 → 서버443이 필요하며 다른 포트로 대체할 수 없습니다. 80 포트는 사용하지 않습니다.
- 다른 프로그램이443을 사용하는 경우 중단하거나 덮어쓰지 않고 충돌을 표시합니다. 기존 OnTechChat 수신기가443인 구성은 기존 인증서 방식과의 충돌을 막기 위해 설정을 거부합니다.
- DNS 전파/CAA/인증기관 요청 제한/외부443 차단 때문에 발급에 실패할 수 있습니다. 설정 저장, 수신기 준비, 인증서 검증, 외부 접속 성공을 구분합니다.
- 인증서와 ACME 계정키는 기존 서버 encryption.key로 암호화하여 DataDir/https-certificates에 저장합니다. 백업에는 이 폴더와 기존 encryption.key를 함께 포함해야 합니다.
- 서버 시작 시 캐시를 재사용하고 자동 갱신합니다. 서버가 계속 실행되고 외부443 연결이 유지돼야 갱신할 수 있습니다.
- 중지하면 추가 HTTPS 수신만 중지합니다. 인증서 캐시와 기존 IP 접속을 보존합니다. 도메인 주소로 접속 중이라면 기존 IP 또는 서버 PC의 설정 화면으로 돌아갑니다.
- 최고관리자만 저장·발급 확인을 요청할 수 있습니다. 기존 Host/Origin/로그인 검사를 유지합니다.
- Windows 방화벽은 이 실행 파일의 TCP443 전용 별도 소유 규칙만 추가합니다. 기존 IP 규칙을 바꾸지 않으며 제거 프로그램이 새 규칙도 함께 정리합니다.
- 기존 Windows 서비스 계정·Caddy·DNS·공유기·다른 프로그램의 방화벽을 변경하지 않습니다.
- 공식 build.ps1 -Target Server -Validation Core로 빌드합니다. 검증 결과/파일 해시는 WORK_STATUS.md에 기록합니다. 실제 운영서버 적용과 공인 인증서 발급 검증은 별도입니다.

네이버 지도 인증 URL은 도메인 HTTPS 접속을 완료한 뒤 실제 앱 접속 주소에 맞게 등록합니다.

## Inno Setup 설치 파일

- 배포 Setup은 Inno Setup 6.7.3으로 생성합니다. 기존 자체 설치 확인창과 Go 실행 파일을 그대로 Setup으로 게시하던 경로를 제거했습니다.
- 유일한 정의는 installer/OnTechChat.iss, 빌드 진입점은 build.ps1입니다. tools/InnoSetup/ISCC.exe를 build.config.json에서 지정합니다.
- 설치 마법사가 내부 실행 파일의 설치 작업을 호출하고 종료 코드를 확인합니다. 실패하면 오류를 표시하고 완료로 처리하지 않습니다.
- 프로그램/데이터 경로·서비스 계정·업데이트 복원·기존 데이터 보존·APK 게시·바로가기·트레이 시작은 기존 제품 수명주기 처리를 유지합니다.
- Windows 앱 제거 항목은 기존 OnTechChatServer 하나를 유지합니다. 중복 Inno 제거 항목은 만들지 않으며 제거 시 데이터 보존/삭제 선택을 유지합니다.
- AI 로그인은 설치 후 트레이 메뉴에서 진행합니다. 설치 도중 별도 로그인 창을 강제로 열지 않습니다.
- 이번 변경만 확인하는 빌드: build.ps1 -Target Server -Validation HTTPSSetup. 기존 Core 검사를 이미 통과한 뒤 HTTPS·설치 변경만 다시 검사합니다.
