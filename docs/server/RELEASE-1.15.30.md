# 서버1.15.30 / Android1.8.7(187) — 앱 로그인 상태 보존
- 사용자 제보: 친구/대화는 보이나 native 상단은 로그인 필요, 설정 진입 후 로그인 화면 복귀.
- SecureState의 읽기 예외 → 빈 LocalState 반환 → 배경 FCM/설정 저장의 기존 로그인 덮어쓰기 경로를 제거했다. 실제 휴대전화 오류 로그로 원인이 확정된 것은 아니다.
- 처음 유효하게 읽은 상태는 메모리에 유지하며 외부 읽기는 복제본을 반환한다. 저장 성공 후에만 메모리 상태를 교체한다. 읽기·복호화·키 접근·쓰기 실패로 원본을 초기화하지 않는다. 저장 파일이 있는 상태에서 키 접근 실패를 새 키 생성으로 처리하지 않는다.
- 서버 연결/로그인 상단 상태와 FCM 등록 상태를 분리한다. 알림 기기 등록 실패를 전체 로그인 만료로 표시하지 않는다.
- 웹 쿠키 저장 결과는 managed Java Boolean 타입 판정 대신 CookieManager의 실제 ontech_session 일치 여부를 확인한다. 이미 맞는 쿠키는 다시 쓰지 않는다. 늦은 콜백/로그아웃/Activity 종료의 화면 재진입은 기존 세션 확인으로 차단한다.
- STATE_READ_FAILED/STATE_SAVE_FAILED/WEB_COOKIE_MISSING/WEB_COOKIE_TIMEOUT 진단을 구분하고 민감정보 없이 오류 단계/타입을 앱 실행 진단에 기록한다.
- 기존 Android Keystore AES-GCM 파일/키/서명과 서버 세션 형식은 유지한다. 앱 삭제/데이터 초기화 필요 없음.
- 서버Setup1.15.30은 공식 APK1.8.7을 포함한다. 운영 설치와 실기기 검증은 이 작업에서 하지 않았다.
