# 가입 없는 이동경로 지도 — Android 1.8.9 / 서버 1.15.32

서버 Setup과 Android 앱을 함께 업데이트하면 OpenFreeMap 벡터 지도를 사용합니다. 회원가입, API 키, 관리자 지도 설정은 필요 없습니다. 확대 시 도로와 글자가 다시 그려집니다. 한글 이름이 있으면 우선 표시하고, 없으면 현지 이름을 사용합니다.

OpenFreeMap은 OpenStreetMap 데이터 기반입니다. 네이버·카카오·브이월드 데이터로 전환한 것이 아니며 국내 상점·도로 누락까지 보완하지는 않습니다. 브이월드 가입/API 키 방식은 사용자 요청에 따라 적용하지 않았습니다.

경로는 흰 테두리의 파란 선, 시작은 초록색, 마지막 측정은 빨간색입니다. 지점을 눌러 시각·오차를 확인합니다. 전체 경로/마지막 위치 버튼과 축척을 제공합니다. 선은 길찾기 결과가 아니라 측정 지점 연결입니다.

## 호환·실패 처리
- 기본 지도 버튼으로 기존 Leaflet/OpenStreetMap 지도로 전환합니다. 자동 조회 시 지도 위치·확대 수준·기본 지도 선택을 유지합니다.
- WebGL 실패, 그래픽 컨텍스트 손실, 배경 타일 응답 지연 시 기본 지도로 전환합니다. 배경 연결 실패 시에도 경로/지점을 표시합니다.
- 한글 스타일과 지도 엔진·워커·아이콘은 서버 자산에 포함합니다. 외부 스크립트를 실행하지 않습니다.
- 구버전 Android는 새 지도 리소스를 차단하므로 함께 업데이트해야 합니다. 기존 지도 fallback은 유지됩니다.

## 위치 공유와 외부 요청
1분 간격 목표/48시간 보관/현재 위치 공유 권한/15초 권한 재검증/로그아웃·조회 실패 시 정리는 유지합니다.
전체 GPS 경로, 계정 ID, 채팅 세션 토큰·쿠키를 지도 제공자에게 보내지 않습니다. 표시 지역의 타일 좌표, 폰트 요청과 IP 등 네트워크 정보는 전달됩니다.
새 외부 요청은 HTTPS tiles.openfreemap.org의 고정 planet 메타데이터·좌표 검증 타일·Noto Sans 폰트 블록 GET만 허용합니다. 내비게이션, POST, 사용자 정보·쿼리·프래그먼트, 임의 호스트/스크립트 경로는 차단합니다. CSP에서 외부 스크립트/unsafe-eval/unsafe-inline을 허용하지 않습니다.
