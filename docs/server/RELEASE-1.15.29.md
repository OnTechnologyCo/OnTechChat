# Android 1.8.6(186) / 서버 1.15.29
- 1.8.5 설치 뒤 즉시 종료 제보. 이전 APK와 비교해 의존 Java 리소스 누락을 확인하여 ARM64 빌드 캐시를 삭제하고 전체 패키지를 다시 생성합니다.
- 공식 Android 빌드는 Java 리소스와 JNI 등록을 다시 생성하며 Kotlin/Firebase/AndroidX 필수 파일 포함을 검사합니다.
- Firebase를 Application에서 명시적으로 초기화하고 초기화/알림 채널 오류가 채팅 앱 시작을 종료하지 않도록 처리합니다.
- 앱 시작 예외의 종류·단계·스택만 기기에 기록합니다. 토큰/로그인 정보/예외 메시지는 수집하지 않습니다. 메뉴 → 앱 실행 진단에서 복사합니다.
- 로그인 영속 유지 및 1.8.5의 자동 복구 수정은 유지됩니다. 앱 삭제/데이터 초기화는 필요 없습니다.
- 실제 제보 기기의 오류 로그 및 실행 검증은 아직 없습니다. 서버 Setup에 새 APK를 포함합니다.
