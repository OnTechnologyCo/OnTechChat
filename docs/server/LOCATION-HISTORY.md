# 이동경로 — Android 1.8.1 / 서버 1.15.15
## 사용
1. 서버 설치기와 Android APK를 업데이트합니다.
2. 기존 내 위치 조회 허용을 켜면 위치 기록을 자동 시작합니다. 이미 켜 둔 기기는 앱을 열 때 서버의 동의/세션을 확인해 시작합니다. 별도 기록 스위치는 없습니다.
3. 신규 허용은 모든 친구(이후 추가된 친구 포함)에게 공유합니다. 기존 선택 공유는 자동 확대하지 않습니다.
4. 내 프로필/친구 프로필 → 이동 경로. 기본 최근1시간,1/2/6/12/24/48시간을 바로 선택합니다.
5. 지도에서 경로·시작·마지막 측정 위치와 시간별 지점을 확인합니다. 마지막 기록이3분 이상 지연되면 안내합니다.
6. 내 위치 조회 허용을 끄면 기록·공유·미전송 큐를 중지합니다. 이미 서버에 전송된 본인 기록은48시간 이내 조회할 수 있습니다.
7. 내 모든 이동 기록 삭제는 모든 기기 기록 및 위치 조회 허용을 해제합니다. 다음 연결 때 기존 큐를 폐기하며 자동 재시작하지 않습니다.
## 수집·보관
- 60초 간격 측정 목표, 측정 후48시간 보관. 실행 중 만료 정리, 종료 상태에서는 다음 실행 시 정리합니다.
- 로컬 미전송 큐3000개, 서버 사용자6000개/전체50000개. 조회 최대3000개, 초과 시 일부 표시를 알립니다.
- Android Keystore AES-GCM에 암호화 보관하고100개씩 전송합니다. 동일 ID 중복 제거 및 내용 변경 거부.
- 세션/기기 소유자/동의 revision/시간/좌표를 검증합니다. 새 앱의 follow_sharing 설정은 기존 위치 조회 허용이 철회되면 업로드도 거부합니다.
- 원문 GPS는 운영 로그·푸시·AI 문맥에 넣지 않습니다. 관리자도 위치 공유 권한을 우회하지 못합니다.
- 기존 암호화 JSON 스냅샷에 호환 필드를 추가합니다. 별도 DB 마이그레이션 없음.
## 지도 및 권한
- 앱1.8.9/서버1.15.32부터 가입·키 없는 OpenFreeMap 벡터 지도를 기본 사용하고 한글 이름을 우선 표시합니다. MapLibre5.24.0 엔진·워커·스타일·아이콘은 서버에 포함하고 타일/폰트만 외부에서 읽습니다. 실패 또는 기본 지도 선택 시 Leaflet1.9.4/OpenStreetMap으로 전환합니다. 자세한 내용: RELEASE-1.15.32.md. 타일 요청에는 표시 지역과 네트워크 정보가 전달되며 채팅 원문/계정 ID/전체 경로 배열은 전달하지 않습니다.
- 지도 출처를 표시하고 브라우저 표준 캐시를 사용합니다. 타일 대량 다운로드·오프라인 지도 저장은 하지 않습니다. 기본 지도 공급자는 서비스 정책/접속 환경에 따라 사용이 제한될 수 있습니다.
- 시간은 조회 기기 시간대로 표시합니다. 지점을 선택하면 시각/좌표/오차를 확인합니다.
- 다른 기기,3분 초과 공백,날짜변경선 구간을 연결하지 않습니다. 선은 측정 지점 연결이며 실제 도로나 이동 수단을 추정하지 않습니다.
- 조회는15초마다 권한을 재검증하고 닫기/로그아웃/실패 때 화면 데이터를 지웁니다.
## 알림·제약
- 기록에는 Android location foreground service를 사용합니다. 숨겨진 서비스나 OS 알림 우회는 구현하지 않습니다.
- 알림 권한이 없어도 기록 시작을 막지 않습니다. 기기 설정의 GPS 이동 기록 채널을 끄면 알림 바 표시를 조절할 수 있습니다. 시스템 실행 중인 앱 표시는 OS가 관리합니다.
- 위치 권한은 필요합니다. GPS 미수신·절전·제조사 정책·강제종료에 따라 공백이 생기며 강제종료/재부팅 후 앱을 열어 재개합니다.
- 오프라인이면 서버 지도는 갱신되지 않고 중지/삭제도 연결 때 서버에 반영됩니다.
## API
- GET/PATCH /api/devices/{id}/location-history: 본인 기기 설정. 신앱 PATCH는 enabled/share_with_friends/follow_sharing/confirmed:true,interval_seconds:60.
- POST /api/devices/{id}/location-history: revision,points. stale revision 재전송 차단.
- GET /api/location-history/{user}?from=Unix초&to=Unix초: 최대48시간, points/count/truncated 반환.
- DELETE /api/location-history: 모든 기기 기록 삭제와 기존 위치 조회 허용 해제.
## 검증
- Go 권한·동의·주기·보관·중복·범위·삭제 검사와 JS 빠른시간 선택/공백/권한회수/로그아웃 검사를 실행합니다.
- 실제 휴대전화 이동/화면 꺼짐/알림 채널/재부팅/장기 보관은 별도 실기기 확인이 필요합니다.
