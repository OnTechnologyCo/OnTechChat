# OnTechChat Server 1.15.35 / Android 1.8.11 (191)

## 메일 제목 조건 여러 개
서버 설정 → 네이버 메일 → 제목에 포함할 문구에 한 줄당 한 조건을 입력합니다.

```text
로그인 코드
이메일 인증
```

- 지정한 폴더에서 제목에 하나라도 포함되면 기존 수신 사용자에게 제목과 본문 텍스트를 한 번 전달합니다.
- 최대 20개, 각 200자. 빈 줄과 중복 조건은 제거합니다. 영어 대소문자·연속 공백은 구분하지 않습니다.
- 쉼표와 정규식 기호는 문구 자체로 비교합니다. 본문만 일치하는 메일은 전달하지 않습니다.
- 기존 단일 조건은 유지하며 기존 subject_filter 필드에 줄바꿈으로 저장합니다.
- 저장 후 적용하면 자동 수집에 반영됩니다. 이전 메일 재확인은 수동 검사 범위 안에서 메일 수집 테스트를 사용합니다. 기존 UID 커서/중복 전달 방지는 유지합니다.

## GitHub 릴리스 업데이트
공식 저장소: https://github.com/OnTechnologyCo/OnTechChat

- 서버: 서버 설정 → 업데이트 → 최신 릴리스 확인 → PC 설치 프로그램 다운로드. 서버를 설치한 PC에서 Inno Setup을 실행합니다. 파일 다운로드가 서버 설치 완료를 의미하지는 않습니다.
- 모바일: 기존 앱 업데이트 확인/자동 확인에서 GitHub 최신 정식 릴리스를 조회하고 APK를 직접 다운로드합니다. 앱 패키지·버전·SHA256·설치된 앱의 서명을 검증한 뒤 Android 설치 화면을 엽니다.
- 공개 릴리스만 사용합니다. 채팅 로그인 토큰/쿠키를 GitHub로 보내지 않으며 HTTPS 및 지정된 GitHub 다운로드 호스트만 허용합니다.
- 최신 릴리스 조회를 10분 캐시합니다. 네트워크 오류/요청 제한/누락된 배포 정보는 오류로 표시하며 채팅 로그인은 유지합니다.
- 기존 서버 APK 배포 API와 Setup의 APK 포함 기능은 이전 앱의 호환을 위해 유지합니다. 새 Android 앱은 GitHub에서 직접 받습니다.
- 취소한 버전의 반복 자동 설치 안내 방지와 Android의 최종 설치 승인은 유지합니다.

## 릴리스 게시 파일
공식 build.ps1 -Target All -Validation MailUpdates로 생성한 다음 파일을 같은 정식 GitHub 릴리스에 게시합니다.

- OnTechChat-Server-Setup-v1.15.35-x64.exe
- OnTechChat-v1.8.11-arm64.apk
- android-update.json (빌드가 검증한 versionCode/서명/크기/SHA256 정보)
- manifest.json, SHA256SUMS.txt

태그는 서버 버전에 맞는 v1.15.35를 사용합니다. 초안/사전 릴리스는 자동 업데이트에서 사용하지 않습니다. APK가 바뀌면 android-update.json도 같은 빌드에서 생성한 파일로 함께 올립니다. 서명키나 계정 인증정보는 게시하지 않습니다.

검증 결과/설치 파일 해시는 WORK_STATUS.md에 기록합니다. 실제 네이버 계정의 메일 전송, 다른 운영 PC 설치 및 실기기 Android 설치는 별도입니다.
