# OnTechChat 1.15.15 / Android 1.8.1 (181)
## AI 첨부
- AI 채팅의 첨부 버튼으로 파일을 올린 뒤 요청 문장을 보내세요.
- 최근 24개 메시지 안의 최신 첨부 최대4개/합계20MB를 전달합니다. PNG/JPEG/GIF/WebP는 실제 이미지 입력, UTF-8 텍스트는 파일당64KB까지 지원합니다. 긴 본문은 문맥 한도에 맞게 일부만 전달합니다.
- GPT-6-Astra + Codex CLI는 기본 image_gen으로 이미지 생성/수정을 수행할 수 있습니다. 계정·모델·CLI에서 지원해야 하며 이미지 결과가 실제 저장된 경우만 채팅에 이미지 파일로 게시합니다.
- OpenAI 호환 API는 모델이 지원하는 이미지 입력을 사용합니다. 현재 Claude CLI 이미지 입력은 명확한 미지원 오류를 반환하며 이미지를 읽었다고 주장하지 않습니다. PDF/Office/압축 파일 자동 해석은 미지원입니다.
- 생성 이미지는 해당 CLI 요청의 generated_images/thread-id만 수집·검증하고 임시 사본을 정리합니다. 계정 홈/인증은 복사하지 않으며 설치 PC의 실행 계정/공용 Codex 설정을 따릅니다.
- AI 대화 전체 삭제는 업로드/생성 첨부도 삭제하고 작업을 취소합니다. 작업공간 파일은 별도입니다.
## 대화방 AI 자동 도움
- 일반 채팅방 상단 AI 도움 체크 한 번으로 활성화합니다. 사용자·대화방별 설정이며 다른 참여자에게 결과가 노출되지 않습니다.
- 서버가10초마다 변경을 확인하고 방별 최소30초 간격으로 최근 텍스트 최대50개를 분석합니다. 앱이 닫혀 있어도 체크한 방은 처리할 수 있습니다.
- 요약·약속/할 일·답장 초안을 제시하고 근거 메시지 확인을 제공합니다. 답장은 입력창에 넣기만 하며 자동 전송하지 않습니다.
- 기존 수동 친구/대화 선택은 AI 화면의 선택 기능으로 남아 있습니다. 자동 모드에 범위 설정·미리보기 승인은 필요하지 않습니다.
- 원문/권한/동의 해제는 호출 전후에 재검증합니다. 결과는 서버 메모리에15분만 보관합니다. 개인정보가 포함된 대화 분석에는 웹/파일/셸/MCP/이미지 생성 도구를 제공하지 않습니다.
## 위치·이동경로
- 기존 내 위치 조회 허용 설정에 따라1분 간격 기록을 자동 시작합니다. 새 위치 허용은 모든 친구 대상이며 예전 선택 공유를 자동 확대하지 않습니다.
- 별도 기록 사용·미사용/친구 경로 공유 스위치는 없습니다. 허용 해제는 기록과 공유를 중지합니다.
- 최근1시간이 기본이며1/2/6/12/24/48시간 버튼을 누르면 즉시 조회합니다. 기록은48시간 보관합니다.
- OpenStreetMap 지도에 이동 선, 측정 지점, 시작/마지막 위치, 시각과 정확도를 표시합니다. 지도의 전체 경로/마지막 위치 버튼을 제공합니다. Android WebView는 공식 HTTPS 지도 타일의 GET 하위 요청만 허용하며 임의 외부 페이지/전송은 허용하지 않습니다.
- 3분 이상 새 측정이 없으면 지연을 표시합니다. 기록의 마지막 위치는 실시간 현재 위치를 보장하지 않습니다.
- 별도 현재 위치 확인 버튼은 제거했습니다. 구버전 호환 API는 유지합니다.
- Android 서비스 알림은 소리/진동/팝업 없이 생성합니다. 알림 권한 거부로 기록을 막지 않습니다. 기록 알림 표시 설정에서 해당 채널만 끌 수 있고 시스템 실행 중인 앱 표시는 OS가 관리합니다.
- 실제 1분 간격은 GPS/절전/제조사/강제종료에 따라 공백이 생길 수 있습니다.
## 화면 여백
- 친구·채팅·설정 하단 메뉴의 강제 최소 높이를 없애고 내부 여백을 축소했습니다. Android가 처리한 하단 안전 영역을 웹 메뉴에서 다시 더하지 않습니다. 시스템 내비게이션 영역은 유지합니다.
## 앱 업데이트
- 로그인한 앱을 열면 새 버전을 확인하고 자동 다운로드한 뒤 패키지/버전/크기/SHA256/서명을 검사합니다.
- Android의 설치 허용 및 최종 설치 화면을 사용합니다. 무인 설치를 보장하지 않습니다. 취소한 동일 버전은 같은 실행 중 반복해서 띄우지 않으며 메뉴에서 재시도할 수 있습니다.
- 서버 Setup에는1.8.1 공식 서명 APK가 포함됩니다. 이전 앱에서 처음1.8.1을 적용할 때는 기존 업데이트 확인 기능 또는 직접 APK 설치를 사용하세요.
