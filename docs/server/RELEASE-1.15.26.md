# OnTechChat Server 1.15.26

## 대화 목록 팝업의 대화방 삭제
채팅 목록에서 대화방을 길게 누르면 정보와 함께 `대화방 삭제`가 표시됩니다.
1:1, 그룹, 개인 인증/메일 수신함, AI 대화 모두 같은 삭제 메뉴를 제공합니다.
삭제 확인 후 내 이전 기록을 비우고 내 대화 목록에서 방을 제거합니다.
다른 참여자의 원본 대화/메일 계정의 원문과 사용자 작업공간은 삭제하지 않습니다.
그룹 탈퇴는 별도의 `대화방 나가기` 메뉴입니다.

## 삭제 후 동작
- 삭제 상태와 본인의 기록 삭제 경계는 서버에 저장되어 다른 기기/재접속에도 적용됩니다.
- 새로운 메시지가 실제로 저장되면 목록에 다시 표시됩니다. 이전 기록은 복원하지 않습니다.
- 1:1 또는 AI 친구를 명시적으로 다시 열어도 이전 삭제 경계는 유지합니다.
- 메일 전달 중복 이력은 보존합니다. 동일 메일 재수집으로 수신함을 되살리지 않습니다.
- AI방 삭제는 기존 응답 취소/첨부 및 문맥 삭제 경로를 사용하며 늦은 결과를 차단합니다.
- 권한은 현재 인증 사용자와 대화방 참여 여부로 확인합니다.

## 적용
서버 Setup을 실제 서버 PC에서 업데이트한 뒤 앱/웹을 다시 열어 확인합니다.
Android APK는 1.8.3을 유지하며 이 변경은 서버 Web UI와 API에 포함됩니다.
운영 PC 자동 설치/서비스 변경은 수행하지 않습니다.
