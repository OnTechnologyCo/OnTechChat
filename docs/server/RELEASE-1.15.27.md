# 1.15.27 / Android 1.8.4(184) — 로그인 유지
- 로그인은 직접 로그아웃하기 전까지 유지됩니다. PC 재부팅, 서버 재시작, 앱 재실행 및 일시적인 연결 실패로 로그인 정보를 삭제하지 않습니다.
- 서버 세션은 기존 암호화 저장소에 영속 저장되며 자동 만료를 없앴습니다. 기존에 유효한 세션만 자동 이전하고 이미 만료·로그아웃·회수된 세션은 복구하지 않습니다.
- 새 기기 로그인 때문에 오래된 기기를 자동 로그아웃하지 않습니다. 최대 64개 로그인을 초과하면 새 로그인을 거절하고 기존 로그인은 보존합니다.
- 앱 시작 시 서버가 중지되어 있으면 로그인 유지/연결 대기 화면을 표시하고 5초 간격으로 재시도합니다. 서버가 복구되면 저장된 인증으로 채팅을 엽니다. 정상 연결 중 인증 확인은 30초 간격입니다.
- 암호화 토큰으로 앱 로그인을 복구하고 연결 확인 후 WebView 쿠키를 갱신합니다. 웹도 인증 확인 시 쿠키 보관 기간(400일)을 갱신합니다.
- SESSION_INVALID가 있는 인증 오류만 로그인 해제로 처리합니다. 프록시 401/403, 5xx, 네트워크 오류, 잘못된 현재 비밀번호 입력으로 로그아웃하지 않습니다.
- 비밀번호 변경/관리자 재설정/계정 사용 중지/역할 변경의 기존 세션 회수 규칙은 유지합니다.
- 서버 설정의 시간제 로그인 유지 항목을 직접 로그아웃까지 유지 안내로 대체했습니다. 기존 session_hours는 설정 호환용이며 새 로그인에는 적용하지 않습니다.
- 서버와 앱을 함께 업데이트해야 합니다. 이미 로그인 정보가 지워진 앱은 최초 1회 다시 로그인해야 합니다.
- 실제 휴대전화/운영 PC 재부팅은 별도 확인이 필요합니다. 자동 검사는 임시 암호화 저장소를 닫고 새 서버로 다시 여는 방식으로 재시작과 세션 영속성을 검증합니다.
