# OnTechChat 1.15.16 / Android 1.8.2 (182)
## 수정 이유
1.8.1 적용 후 앱 실행 불가/버전 확인 문제 제보에 대응합니다. 실제 휴대전화 종료 로그는 확보하지 못했으므로 제보 원인을 확정했다고 보고하지 않습니다.
코드에서 설치 안내 취소 후 pendingInstall 유지, pending 경로의 작업 잠금 누락, 시작 화면보다 빠른 자동 업데이트, UI 스레드의 APK 반복 해시 검사를 확인하고 수정했습니다.
## 변경
- 서버 웹 화면 로드 성공 후8초 뒤 자동 확인. 로딩/오류 화면 및 중복 resume/page-finished에서 자동 설치를 시작하지 않습니다.
- 버전 조회8초 제한, 오류는 업데이트만 건너뛰고 채팅/로그인을 유지합니다.
- 버전 확인·다운로드·대기 설치를 동일한 작업 잠금으로 처리합니다. APK 검증은 백그라운드 작업으로 수행합니다.
- 설치 안내 취소·권한 거부·설치창 진입 시 해당 계정/버전을 기억해 자동 안내가 반복되지 않습니다. 메뉴의 수동 업데이트와 더 높은 새 버전은 허용합니다.
- 이미 설치한 버전/이전 버전은 설치창을 열지 않습니다. 검증·다운로드 실패, 화면/계정 전환 시 진행 상태를 정리합니다.
- 앱 시작 시 불필요한 암호화 상태 재저장을 제거하고, 비동기 웹 화면 생성 예외를 로그인 오류 처리로 전달합니다.
- 서명/패키지/버전/크기/SHA256 검증과 Android 설치 동의는 유지합니다.
## 배포
- output/OnTechChat-v1.8.2-arm64.apk
- output/OnTechChat-Server-Setup-v1.15.16-x64.exe
- 기존 앱을 삭제하지 않고 동일 서명의 새 APK를 덮어 설치합니다. 실행이 막힌1.8.1에서는 앱 내 업데이트 대신 직접 APK 설치로 복구합니다.
- 서버 Setup은 새 APK 게시용이며 기존 서버 API와 호환됩니다. 운영 서버 자동 설치/재시작은 하지 않습니다.
## 검증 범위
- UpdateCheckGate 회귀: 시작 전 차단, 중복 실행, 오류 해제, 동일/이전 버전, 취소 후 재실행, 수동 재시도, 계정 경계.
- 실제 Chrome에서 테스트용 API로 전체 웹 스크립트를 로드했으며 시작 오류0/채팅 화면 표시 확인. 사용자 계정·운영 데이터는 사용하지 않았습니다.
- 빌드/서명/해시는 docs/WORK_STATUS.md. 실기기 또는 Android 에뮬레이터 실행은 미검증(연결된 기기/설치된 에뮬레이터 없음).
