# 지도 라이선스 및 변경 고지

MapLibre GL JS 5.24.0, OpenFreeMap Liberty/아이콘을 포함합니다. 지도 스타일은 한국어 우선 이름과 서버 내부 아이콘 주소로 수정하고 Natural Earth 배경을 제외했습니다. 원본 링크와 조건은 아래에 보존합니다.
